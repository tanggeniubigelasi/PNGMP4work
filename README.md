# 批量文件水印工具

一个基于 Python、Tkinter、Pillow 和 FFmpeg 的桌面批处理工具，可递归扫描文件夹，为图片和 MP4 视频添加文字水印或图片水印，并将结果保存到独立输出目录。

## 功能

- 递归扫描输入目录及所有子目录。
- 支持 PNG、JPG、JPEG、WEBP、BMP、TIF、TIFF 静态图片，以及 MP4 视频。
- 支持文字水印和图片水印。
- 文字可设置字体文件、颜色、透明度、描边和阴影。
- 图片水印可调整透明度。
- 支持九宫格定位、满屏平铺、间距和 45° 旋转。
- 图片与视频的水印宽度分别设置。
- 图片和视频共用 Pillow 生成的水印图层；视频以 1:1 像素叠加，避免二次拉伸。
- 描边和阴影以 1920×1080 为参考分辨率自动适配，降低不同分辨率媒体在等比例预览时的视觉差异。
- 保留输入文件名、扩展名和相对目录层级，不修改源文件。
- 显示批次进度、处理日志，支持停止后续处理。
- 支持中文路径和带空格的文件名。

## 运行环境

- Windows 10 / Windows 11
- Python 3.10 或更高版本
- Tkinter（通常随 Windows 版 Python 安装）

依赖：

- Pillow
- imageio-ffmpeg（提供 FFmpeg 可执行文件）

## 快速开始（Windows）

1. 下载或克隆本仓库。
2. 安装 Python 3.10+，安装时建议勾选 `Add Python to PATH`。
3. 双击 `安装依赖.bat`。
4. 双击 `启动工具.bat`。
5. 选择输入文件夹、输出文件夹和水印设置，点击开始。

也可以在命令行运行：

```bash
py -m pip install -r requirements.txt
py "批量文件水印工具.py"
```

## 输出目录示例

输入：

```text
原始素材/
├─ 封面.png
└─ 项目A/
   ├─ 角色立绘.jpg
   └─ 视频资料/
      └─ 展示视频.mp4
```

输出：

```text
水印结果/
├─ 封面.png
└─ 项目A/
   ├─ 角色立绘.jpg
   └─ 视频资料/
      └─ 展示视频.mp4
```

输出文件名和原目录层级保持一致。请将输出目录设在输入目录之外；程序会阻止输入目录与输出目录完全相同。

## 描边大小如何理解

描边粗细使用 **1080p 参考像素**：

- 1920×1080：设置 4，实际描边约 4 px。
- 3840×2160（4K）：设置 4，实际描边约 8 px。
- 1280×720：设置 4，实际描边约 3 px。

这是为了在图片或视频缩放到相同预览尺寸时，让描边保持近似的视觉粗细。视频经过 H.264 和色度抽样后，极细彩色描边仍可能有轻微柔化，这是视频编码的正常现象。

## 调整窗口与字体

打开 `批量文件水印工具.py`，在文件顶部找到“窗口与界面外观”区域：

```python
WINDOW_GEOMETRY = "1240x1040"
WINDOW_MIN_WIDTH = 1050
WINDOW_MIN_HEIGHT = 780
UI_FONT_SCALE = 0.8
```

- `WINDOW_GEOMETRY`：启动时窗口宽度和高度，例如 `"1400x1000"`。
- `WINDOW_MIN_WIDTH` / `WINDOW_MIN_HEIGHT`：窗口可缩小到的最小宽高。
- `UI_FONT_SCALE`：相对 V2 字号的比例。`0.8` 表示缩小 20%；`1.0` 表示恢复 V2 字号；`0.9` 表示缩小 10%。

修改后保存并重新启动程序。

## 字体文件

字体文件是实际储存字形数据的 `.ttf`、`.ttc` 或 `.otf` 文件。例如 Windows 常见字体目录为 `C:\\Windows\\Fonts`，其中可能包含微软雅黑、黑体和宋体。程序不会把系统字体复制或打包进仓库；请使用自己有权使用的字体文件。

## 当前限制

- 暂不处理动态 WebP/TIFF；检测到多帧文件会跳过，避免丢失动画。
- 当前视频输入支持 MP4。
- 视频画面重新编码为 H.264；音轨优先复制，失败时回退为 AAC。
- 高分辨率或长视频的处理时间较长。
- 极细彩色描边在 H.264 4:2:0 输出中可能略微柔化。
