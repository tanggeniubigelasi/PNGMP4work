批量文件水印工具 V3 - 使用说明
========================================

一、V3 本次修改内容
----------------------------------------
1. 保留并修复 V2 的滑块初始化顺序，避免启动时回调访问尚未创建的标签。
2. 在 V2 纵向滚动页面的基础上，将全局字体统一缩小 20%，同时保留可配置的窗口尺寸。
3. 图片和视频的水印宽度分开设置：图片宽度、视频宽度互不影响。
4. 修复视频文字水印纵向拉伸：不再使用 scale2ref 二次动态缩放，而是按视频实际画面宽高生成同尺寸水印图层，再按 1:1 像素叠加。
5. 文字水印增加描边开关、描边粗细、描边颜色。默认关闭。
6. 文字水印和图片水印分别提供透明度设置。
7. 文字水印增加阴影开关、阴影颜色、X/Y 偏移和模糊程度。
8. 增加满屏平铺水印，以及平铺间距设置。
9. 文字水印和图片水印均支持开启/关闭 45° 旋转。
10. 修复视频循环水印层导致 FFmpeg 等待不结束的问题，确保叠加过程随视频画面正常结束。
11. 全局字体相对 V2 统一缩小 20%，普通控件约 14px、标题约 25px、日志约 14px。
12. 描边粗细改为以 1920×1080 为参考分辨率，按画面像素总量的平方根自动适配；阴影偏移和模糊同步适配，减少不同分辨率文件的视觉差异。
13. 将窗口尺寸、最小窗口尺寸和界面字号比例集中到源码顶部，方便自行修改。

二、功能
----------------------------------------
1. 选择一个输入文件夹，程序会递归扫描其中所有子文件夹。
2. 支持图片：PNG、JPG、JPEG、WEBP、BMP、TIF、TIFF。
3. 支持视频：MP4。
4. 支持文字水印和图片水印两种类型。
5. 支持中文文字、字体选择、文字颜色、文字透明度。
6. 文字水印支持可选描边和可选阴影。
7. 图片水印支持独立透明度设置。
8. 支持单个水印位置、满屏平铺、平铺间距、45° 旋转。
9. 图片与视频分别设置水印宽度百分比。
10. 输出文件名、扩展名和相对目录层级与输入保持一致。
11. 不修改输入目录内的原文件。
12. 支持处理过程日志和停止当前批次。

三、运行环境与安装
----------------------------------------
- Windows 10 / Windows 11
- Python 3.10 或更高版本
- Pillow
- imageio-ffmpeg
- Tkinter（通常随 Windows 版 Python 一起安装）

安装步骤：
1. 将完整工具包解压到本地文件夹。
2. 双击“安装依赖.bat”。
3. 等待依赖安装完成。
4. 双击“启动工具.bat”。

如电脑没有 py 命令，请安装 Python，并在安装时勾选将 Python 添加到 PATH。

四、页面大小和字体大小如何修改
----------------------------------------
打开“批量文件水印工具.py”，在文件顶部“窗口与界面外观”区域修改：

    WINDOW_GEOMETRY = "1240x1040"
    WINDOW_MIN_WIDTH = 1050
    WINDOW_MIN_HEIGHT = 780
    UI_FONT_SCALE = 0.8

- WINDOW_GEOMETRY 控制启动时窗口宽度和高度，例如改为 "1400x1000"。
- WINDOW_MIN_WIDTH / WINDOW_MIN_HEIGHT 控制窗口允许缩小到的最小尺寸。
- UI_FONT_SCALE 控制界面字号比例；0.8 表示相对 V2 缩小 20%，1.0 表示恢复 V2 字号。
修改后保存并重新启动程序。运行时也可以直接拖动窗口边缘调整大小。

五、字体文件是什么意思
----------------------------------------
“字体文件”就是实际存储字体字形、字形轮廓和相关字体信息的文件。它决定文字最终呈现的字形样式。

常见例子：
- 微软雅黑：msyh.ttc / msyh.ttf
- 黑体：simhei.ttf
- 宋体：simsun.ttc
- 等线：Deng.ttf

.ttf、.ttc、.otf 是字体文件格式，不是普通 TXT 文本文件，也不是在输入框里键入“黑体”两个字。

字体文件会影响字形外观，例如笔画粗细、字面结构和风格。若想让水印文字显示为黑体或宋体，需要选择对应字体文件。

Windows 常见字体目录：
C:\Windows\Fonts

程序默认会尝试自动寻找微软雅黑、黑体或宋体。自动选择不合适时，可点击“选择字体”手动选择 .ttf、.ttc 或 .otf 文件。中文水印建议选用支持中文的字体。

六、操作步骤
----------------------------------------
1. 在“输入与输出”中选择输入文件夹和输出文件夹。
   - 选择输入目录后，程序会自动建议“原文件夹名_水印输出”作为输出路径。
   - 输入目录和输出目录不能相同。
2. 在“水印内容”中选择文字水印或图片水印。
3. 文字水印：填写内容，设置字体文件和文字颜色。
   图片水印：选择图片文件，透明背景 PNG 通常更适合用作 Logo 水印。
4. 按需设置文字描边、阴影、透明度、水印尺寸和位置。
5. 需要铺满画面时，勾选“开启满屏平铺水印”。
6. 需要斜向水印时，勾选“水印倾斜 45°”。
7. 检查预设后，点击“开始批量添加水印”。
8. 处理结果会写入输出文件夹，日志显示成功、失败和跳过数量。

七、各设置项说明
----------------------------------------
【图片水印宽度】
只影响静态图片文件。数值表示水印宽度占图片画面宽度的比例。例如 20% 表示水印宽度约为图片宽度的五分之一。

【视频水印宽度】
只影响 MP4 视频。数值表示水印宽度占视频画面宽度的比例。该参数与图片水印宽度相互独立。

【文字水印透明度】
只影响文字水印。0% 完全透明，100% 完全不透明。

【图片水印透明度】
只影响图片水印。程序会在原图透明通道的基础上继续调整透明度，不会把透明 PNG 强行变成不透明图片。

【描边】
默认关闭。开启后会在文字轮廓外增加一圈描边。
- 描边粗细：以 1920×1080 为参考分辨率。设置 4 时，1080p 约为 4px，4K 约为 8px，720p 约为 3px。这样文件缩放到相近的预览大小时，描边视觉粗细更一致。
- 描边颜色：通过颜色选择器设定。

【阴影】
默认关闭。开启后在文字下方绘制阴影。阴影偏移和模糊值也会根据画面分辨率按同一参考比例缩放。
- 阴影颜色：设置阴影颜色。
- 偏移 X：控制阴影向左或向右偏移，正数向右，负数向左。
- 偏移 Y：控制阴影向上或向下偏移，正数向下，负数向上。
- 模糊：控制阴影边缘柔化程度，0 表示不模糊。

【水印位置】
单个水印模式下使用九宫格位置：左上、顶部居中、右上、左侧居中、正中央、右侧居中、左下、底部居中、右下。

【边距】
控制单个水印与画面边缘之间的距离百分比。满屏平铺模式下不使用该参数。

【满屏平铺水印】
开启后，程序会在整个画面重复放置水印。水印间距以水印自身的宽度和高度为基准：
- 0%：水印之间基本紧贴。
- 100%：水印之间的空隙约等于水印本身的尺寸。
- 数值越大，水印越稀疏。
开启满屏平铺后，单个水印位置和边距不再生效。

【水印倾斜 45°】
同时适用于文字和图片水印。开启后水印向 45° 方向旋转，程序会扩展水印图层边界，避免旋转后的内容被直接裁掉。

八、视频处理说明
----------------------------------------
1. MP4 视频通过 FFmpeg 添加水印。
2. 程序先提取视频首帧，取得 FFmpeg 自动处理旋转后的实际画面宽高。
3. 根据该宽高生成完全同尺寸的水印透明图层，再按 1:1 像素叠加。此方式避免文字水印被非等比缩放造成纵向拉伸或横向压扁。
4. 视频画面会重新编码为 H.264；音轨优先尝试直接复制，失败时自动转为 AAC。
5. 视频重新编码耗时取决于视频时长、分辨率和电脑性能。
6. 若输入视频的音轨本身比视频画面短，音轨仍保持源文件自身时长，不会为了对齐水印而强行延长。

十、注意事项
----------------------------------------
1. 请先选择少量文件测试水印大小、透明度和位置，再处理整个素材库。
2. 输出目录中如已存在同名文件，程序会询问是否覆盖；选择否时跳过已有输出文件。
3. 无论选择覆盖还是跳过，输入目录中的原文件都不会被修改。
4. 当前版本处理静态图片。检测到多帧动态 WebP/TIFF 时会跳过，避免静默丢失动画。
5. 当前版本只处理 MP4，其他视频格式不会处理。
6. 若中文显示为方框或出现字体读取错误，请在字体文件处选择 C:\Windows\Fonts\msyh.ttc（微软雅黑）或 simhei.ttf（黑体）。
7. 满屏水印的尺寸过小、间距过密时会产生大量重复图层，处理速度和输出文件大小会增加。建议先适当增大间距。
8. 旋转 45° 后，水印的外接矩形会变大，因此视觉上可能比水平状态更占空间。

十一、依赖安装失败时
----------------------------------------
可以在命令提示符中进入本工具所在文件夹，执行：

    py -m pip install Pillow imageio-ffmpeg

然后运行：

    py 批量文件水印工具.py

十二、打包成 EXE（可选）
----------------------------------------
安装 PyInstaller：

    py -m pip install pyinstaller

打包命令：

    py -m PyInstaller --noconfirm --onefile --windowed --name 批量文件水印工具 批量文件水印工具.py

打包后在 dist 文件夹中找到 EXE。建议在目标电脑先进行小批量测试。若打包版自动识别不到 FFmpeg，可将 ffmpeg.exe 放在 EXE 同一目录。
